# 工试分流考回忆题

## 1. 题号分配方案

入群的同学每人会被分到一个id，设卷子总题目数为L，则每个人回忆的考题范围为：

```python
from typing import List

def questionsById(id: int, L: int) -> List[int]:
    q1, q2, q3 = 2*id-1, 2*id, 2*id+1
    q1 = (q1-1)%L + 1
    q2 = (q2-1)%L + 1
    q3 = (q3-1)%L + 1
    return [q1, q2, q3]
```

```cpp
#include <vector>

std::vector<int> questionsById(int id, int L){
    int q1 = 2*id-1, q2 = 2*id, q3 = 2*id+1;
    q1 = (q1-1)%L + 1;
    q2 = (q2-1)%L + 1;
    q3 = (q3-1)%L + 1;
    return {q1, q2, q3};
}
```

## 2. 说明

1. id、题号的编号都从1开始
2. 如果题号是中断的，则靠后题号应视为靠前题号的顺延
3. 一个小题题干视为一题，可以是ABCD四选一，可以是包含多个填空的题干

* 例1: 数学题号是1-16、逻辑题号是1-22，数学在逻辑前，则逻辑题号应视为17-38
* 例2：逻辑题一个大题下面有3个小题题干，每个小题是一个ABCD四选一，若小题试卷编号为`二、1`，`二、2`，`二、3`，且`二、1`上一题编号为7，则这三个小题的编号应视为8、9、10
